พร้อม

สรุปวันนี้ (Today Summary)

วันที่ รหัส ชื่อ สาขา ระดับ t1 t2 t3 t4 สถานะ หมายเหตุ/ลา โลเคชั่น แผนก
กด “โหลด/รีเฟรช” เพื่อดึงข้อมูล
*ข้อมูลนี้เรียก action getTodaySummary (public)

อนุมัติใบลา (Admin)

ส่งเมื่อ รหัส ชื่อ ประเภท ช่วงลา รวม สถานะ การทำงาน
กด “โหลดใบลา” เพื่อดึงข้อมูล
*เรียก action adminListLeaveRequests / adminApproveLeave / adminRejectLeave / adminCancelLeave (ต้องมี token)

พนักงาน (Employees)

ID รหัส ชื่อ-สกุล สาขา ระดับ แผนก อีเมล การทำงาน
กด “รีเฟรช” เพื่อดึงข้อมูล
*เรียก action getEmployees / saveEmployee / deleteEmployee (ต้องมี token)

Resigned / พนักงานลาออก

รายชื่อพนักงานที่ถูกย้ายออกจาก Employees (Active)

รหัส ชื่อ สาขา แผนก ระดับ ลาออกเมื่อ หมายเหตุ จัดการ

ตารางหยุดรายสัปดาห์ (WeeklyOff)

เลือก “วันหยุด” ของแต่ละคน (1–7 = จันทร์–อาทิตย์) แล้วกดบันทึก
รหัส ชื่อ สาขา แผนก วันหยุด (DOW)
กด “โหลด” เพื่อดึงข้อมูล
*เรียก action adminGetWeeklyOff / adminSaveWeeklyOffBulk (ต้องมี token)

วันหยุด/วันพิเศษรายบุคคล (EmployeeOffDates)

date code ชื่อ แผนก kind note การทำงาน
กด “รีเฟรช” เพื่อดึงข้อมูล
*เรียก action adminListEmployeeOffDates / adminSaveEmployeeOffDate / adminDeleteEmployeeOffDate (ต้องมี token)

Logs รายวัน (ตามเดือน)

ถ้าเลือกวันที่ ระบบจะดึงเฉพาะวันนั้น (ไม่สนเดือน/ปี)
วันที่ รหัส ชื่อ สาขา ระดับ t1 t2 t3 t4 สถานะ หมายเหตุ/ลา โลเคชั่น แผนก
กด “โหลด Logs” เพื่อดึงข้อมูล
*เรียก action getLogsRange (ต้องมี token)

Summary สรุป (ตามเดือน)

รหัส ชื่อ สาขา ระดับ ปกติ สาย ขาด หมายเหตุ
กด “โหลด Summary” เพื่อดึงข้อมูล
*เรียก action getSummaryRange (ต้องมี token)

สาขา (Branches)

ชื่อสาขาการทำงาน
กด “รีเฟรช”

ระดับ (Levels)

ชื่อระดับการทำงาน
กด “รีเฟรช”
*เรียก action getBranchesLevels / saveBranch / deleteBranch / saveLevel / deleteLevel (ต้องมี token)

แผนก (Departments)

deptId ชื่อแผนก sort note การทำงาน
กด “รีเฟรช” เพื่อดึงข้อมูล
*เรียก action getDepartments / saveDepartment / deleteDepartment (ต้องมี token)
